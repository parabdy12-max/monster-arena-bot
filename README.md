# تاج سیاه: فساد

پروژهٔ بازی دوبعدی Side-View برای Android با Godot Engine 4.7.2 Stable.

این مخزن برای جایگزینی پروژهٔ قدیمی Monster Arena با پروژهٔ Godot در نظر گرفته شده است.

## وضعیت فعلی
این commit فقط README را مقداردهی اولیه می‌کند. پروژهٔ کامل، صحنه‌ها، اسکریپت‌ها، کتابخانهٔ Asset و Workflow تست هنوز باید به مخزن افزوده و در Godot آزمایش شوند.
